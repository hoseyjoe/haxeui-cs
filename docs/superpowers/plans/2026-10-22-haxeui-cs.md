# haxeui-cs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A composite HaxeUI backend for Haxe 4.3.7's C# target that renders through Avalonia 12 on .NET 10, proven by running JoeClash's Joeditor on it.

**Architecture:** Two layers in one haxelib.
- A small C# **native layer** (`native/*.cs`, namespace `HaxeUICs`) owns everything Avalonia: host bootstrap, a custom panel that paints HaxeUI styles, text, text input, images, vector graphics, file dialogs and a headless test driver. It knows nothing about HaxeUI.
- The Haxe **contract layer** (`haxe/ui/backend/*Impl.hx`) implements haxeui-core-joe's 20 backend files on top of externs to those C# classes.
- A build macro turns `haxe app.hxml` into generated C#, a generated `.csproj`, `dotnet build`, and optionally a run.

**Tech Stack:** Haxe 4.3.7 (`-cs`, `-D no-compilation`), .NET SDK 10 (`net10.0`), Avalonia 12.1.4 (+ Avalonia.Headless for tests), haxeui-core-joe, utest.

**Spec:** `docs/superpowers/specs/2026-10-22-haxeui-cs-design.md`. Read it first.

## Global Constraints

- Haxe 4.3.7 C# target with `-D no-compilation`. Never `-net-lib`, never hxcs's own build, never `-D erase-generics`.
- `net10.0`. Every Avalonia package is pinned to `12.1.4`. Check Avalonia API details against the restored assemblies, not memory.
- Core is haxeui-core-joe (`haxelib dev haxeui-core` → `C:\HaxeToolkit\haxe\lib\haxeui-core\haxeui-core-joe`).
- Core fixes:
  - `#if cs`-guarded, or correct on every target;
  - one small commit each, straight to that repo's `master`;
  - never forked into the backend.
- JoeClash:
  - edits only in the worktree `D:\_github\_JoeClash-cs` on branch `joeditor-cs`;
  - never touch `D:\_github\_JoeClash` (Joe's checkout, with uncommitted work);
  - follow JoeClash's `CLAUDE.md`;
  - don't merge.
- The joenimating repo is not touched.
- Nothing is pushed anywhere. haxeui-cs: commit after each task.
- Composite backend. Each component *owns* a native panel; it doesn't extend one.
- Canvas fill semantics match Joe's haxeui-heaps fork:
  - `fillStyle(c)` begins a fill and `fillStyle(null)` ends it;
  - the `moveTo`/`lineTo` path drawn in between is filled even without `beginPath`.
- System fonts by family name only (size, bold, italic, underline, colour). No font files.
- Verification is on Windows. Joeditor's `FigurePane` and joenimating's Animate pane are placeholders under `haxeui_cs`.
- Generated `.csproj` details from the spike:
  - `Nullable` disabled;
  - `AllowUnsafeBlocks`;
  - `NoWarn` `CS0108;CS0114;CS0162;CS0164;CS0168;CS0169;CS0219;CS0414;CS0649;CS0659;CS0661;CS1717;CS8981`;
  - `EnableDefaultCompileItems` false;
  - `<EmbeddedResource Include="src/Resources/*" LogicalName="Resources.%(Filename)%(Extension)" />`.
- Haxe 4.3 emits top-level classes in the global C# namespace (`global::Main`).

## Review Focus

1. **Window resize after first layout.** Percent-sized root components must re-lay out to the new client size. Test: `TestLayout.testWindowResizeRelayout` (Task 3).
2. **Non-ASCII text round-trips exactly** through TextBlock, TextBox and Save: curly quotes, em-dashes, accented names, as in the story text. Tests: `TestTextInput.testUnicodeRoundTrip` (Task 9) and the acceptance diff (Task 14).
3. **Closing the window exits the process** even while a repeating `haxe.Timer` or `haxe.ui.util.Timer` is running. Haxe's post-`main` `events.loop()` would otherwise wait forever. Test: the `tests/exit-app` check (Task 4).
4. **Screen-level popups.** A dropdown list, tooltip or message box draws above everything, receives clicks, and closes on an outside click. Test: `TestGallery.testDropdownPopup` (Task 12).
5. **Mouse wheel over nested scroll areas** scrolls the innermost one under the pointer, including a long treeview. Test: `TestMouse.testWheelScrollsInnermost` (Task 8).

## File Structure (haxeui-cs)

```
haxelib.json                  name "haxeui-cs", classPath "haxe", dependencies { "haxeui-core": "" }
extraParams.hxml              -D no-compilation, -D haxeui_cs, --macro haxe.ui.backend.cs.macros.Build.configure()
native/                       C# (namespace HaxeUICs) compiled into every app by the generated .csproj
  Host.cs                     IHostListener, ICallback, Host (desktop + headless bootstrap, Post, timers, Exit)
  UIPanel.cs                  UIStyle, UIPanel : Canvas, ICustomHitTest; IPanelListener; EventKind consts
  UIText.cs                   UIText : TextBlock
  UITextInput.cs              ITextInputListener, UITextInput : TextBox
  UIImage.cs                  UIImage (decoded bitmap), UIImageView : Control
  UIGraphics.cs               UIGraphics (recorded draw commands, Flash-style fills)
  FileDialogs.cs              IFileDialogListener, FileDialogs
  TestDriver.cs               headless input, pumping and capture (compiled only with haxeui_cs_headless)
haxe/ui/backend/              the 20 contract files haxeui-core-joe expects + module.xml
haxe/ui/backend/cs/
  native/Native.hx            Haxe externs for every HaxeUICs type (@:native("HaxeUICs.X"))
  Callbacks.hx                Haxe adapters implementing ICallback / listener interfaces from closures
  EventMapper.hx              EventKind ⇄ HaxeUI event type tables, Avalonia Key name ⇄ HaxeUI keyCode
  StyleMapper.hx              haxe.ui.styles.Style → HaxeUICs.UIStyle
  TestDriver.hx               public Haxe test-support API (wraps HaxeUICs.TestDriver)
  macros/Build.hx             post-generate: write .csproj, dotnet build, optional run
templates/App.csproj          template the macro fills (::PACKAGES::, ::NATIVE_DIR::, ::OUTPUT_TYPE::)
tests/headless.hxml           builds + runs the utest suite headlessly
tests/TestMain.hx             utest runner; -D test=<Case> runs one case
tests/cases/*.hx              one file per task below
tests/assets/                 small PNGs used by image tests
tests/exit-app/               desktop-mode app for the exit check (Task 4)
```

`-D haxeui_cs_headless` selects the headless host and adds `Avalonia.Headless`. `-D haxeui_cs_run` runs the app after building. `-D haxeui_cs_no_dotnet` stops after writing the `.csproj`.
